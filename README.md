# FridgeMate 🥬

**Stop wasting food. Start cooking.**

FridgeMate is a grocery expiration tracking application designed to help users monitor their food products, keep track of expiration dates, and reduce unnecessary food waste.

The application allows users to scan food products, manage their grocery inventory, and receive notifications about items approaching their expiration dates.

🌐 **Website Prototype:** [FridgeMate Website](https://fridgemate-website.netlify.app/)

## Features

- **Food Tracking:** Keep track of grocery items and their expiration dates.
- **Barcode Scanning:** Scan food products to simplify adding items.
- **Expiration Indicators:** Color-coded indicators help users identify expiration proximity.
  - 🟢 Green – Not close to expiration.
  - 🟠 Orange – Approaching expiration.
  - 🔴 Red – Close to expiration.
- **Notifications:** Receive reminders about upcoming expiration dates.
- **Inventory Management:** Add, view, and delete grocery items.
